# E2: twenty pairs, run clean

The experiment this project exists for: the same task, the same model, one arm told
CodeSextant is installed and one arm not, paired. Pre-registered in
`experiments/exp19_e2.py` and drawn by seed **before the first agent ran**;
`experiments/e2_plan.json` is the draw.

40 trials, **3,611,354 tokens**. Raw per-trial records in `e2_trials.json`, the
computed report in `e2_report.json`.

## The result

**The tool did not change what was found. In 20 of 20 pairs both arms edited exactly
the same subset of the true companion files.** Not the same number — the same files.
Eleven pairs edited different file *sets*, but every difference lay outside the truth
set, which is why all three quality modes read a difference of exactly 0.000 with a
zero-width interval. That is an identity, not a null washed out by noise.

**On cost, no effect is detectable.**

| | with tool | without | difference | 95% interval | excludes zero |
|---|---|---|---|---|---|
| tokens, pooled | 87,758 | 92,810 | **−5,052 (−5.4%)** | [−14,158, +2,711] | no |
| · convention (7) | 85,340 | 100,090 | −14,750 | [−35,285, +1,944] | no |
| · grep_reachable (7) | 79,110 | 81,418 | −2,308 | [−8,818, +4,890] | no |
| · **hidden (6)** | 100,668 | 97,607 | **+3,061** | [−7,460, +13,600] | no |
| seconds, pooled | 560 | 638 | −78 | [−203, +25] | no |
| tool calls, pooled | 47.6 | 49.3 | −1.75 | [−7.2, +3.6] | no |

The pooled point estimate favours the tool by 5.4%, and the sign test does not: **11
pairs of 20 cheaper with the tool, 9 more expensive.** Per-pair deltas run from −36.6%
to +25.4%. The standard deviation of the per-pair difference is **19,537 tokens —
3.9× the mean difference it is supposed to resolve.**

**`hidden` is the stratum the tool exists for, and its point estimate has the wrong
sign.** Six pairs cannot settle that either, but it is the opposite of what the design
predicted, and it is recorded as measured rather than explained away.

## What this is not

**It is not "the tool costs 14.4% more".** That was the void nine-pair pilot, and two
faults in it pointed the same way: the checkouts carried the answer, and the shim did
not export `CODESEXTANT_HOME`, so every `with_tool` arm paid a full re-index inside its
own token budget. Both are fixed here. The direction reversed.

**It is not "the tool saves 5.4%".** The interval includes zero, the sign test is a
coin flip, and the runner's own token figure moved 2.2% between two reports of the
same agent (168,556 vs 164,917 for run_17, tool calls identical at 114). An effect of
this size is not resolvable by this instrument at this sample size.

**It is not "the tool was ignored".** Every one of the 20 `with_tool` arms invoked it:
**71 invocations — 23 `preflight`, 25 `guards`, 23 `check`** — 3 to 5 per trial. And no
`without_tool` arm ever reached the binary.

## What it would take

At the observed variance, 80% power needs:

| to detect | pairs |
|---|---|
| the observed 5.4% | 118 |
| 10% | 35 |
| 20% | 9 |

So twenty pairs was enough to rule out a large effect and never enough to resolve a
small one. **A 20% cost saving would have shown up here. It did not.**

## Validity

Every trial was checked, not a sample of them.

- `exp14.leaks` clean before each of the 40 agents started: the reference commit's
  object is absent, `git fsck` reports nothing dangling, one ref, no remotes, HEAD at
  the parent, ancestors intact.
- **Zero contaminated.** `contaminated()` reads the git log and the transcript's tool
  calls for a fetch of this task's upstream, and reads every transcript for another
  trial's checkout — the paired arm's above all, since it holds the same task worked
  out. None found either.
- Remote `git`, `curl` and `wget` refused a code host container-wide for the whole run.
- Two trials touched an unrelated trial's checkout (an agent had `pip install -e .`'d
  its own tree into the shared environment). Recorded, not voided: neither shared a
  task, so it cost effort rather than leaking an answer.

## Caveats that belong on any quote of these numbers

1. **Equal allocation across strata. The pooled row is a summary of this sample, not an
   estimate of the average real change** — exp17 put real commits at ~7% hidden, so
   this sample over-represents `hidden` roughly fourfold.
2. `changed_a_broke_b` and `forgot_the_guard` are **recall**. A shotgun that edits every
   Python file scores 1.00 on both. Read them as "did it find them", never as "did it
   change the right set".
3. `rebuilt_the_wheel` scored on **one** pair. It says nothing.
4. Twenty pairs, one model, three repositories, and the prompt in both arms forbids
   consulting upstream — which is not how an agent works in the wild.
