2. **要改還是要砍**：要改（補前/後處理鏈），不砍主軸。
3. **天花板 vs 架構缺陷**：紅隊 R5(相容 lens) 主推換 force-directed＝**架構缺陷誤判**。研究 R2 自證 force「本質非確定性、依初始狀態、卡局部極小、float error 使確定性脆弱」(PMC4051631)，直接違反 user 期許②最高優先的「不要隨機」；且 force 對 user 期許①只是間接（力平衡近似）vs spectral 直接（座標＝結構閉式解）。紅隊把「精修角色」（草案 §7 Phase2 已列 force/stress 為可選精修）誤升格成「主軸角色」。

### 2.1 後端核心函數 compute_layout（export_graph.py 增量）

**插入點（R1 鐵證修正）**：real 端 **line 117 後、line 119 前**（edges 迴圈結束、out 組裝前）；synth 端 line 180(add_edge 全跑完)後、out 前。⛔ 草案說的「line 91-100 nodes.append 後」是 NameError，作廢。

```python
def compute_layout(n_nodes, edges, ranks, dim=3, target_radius=1700.0):
    """確定性 3D spectral 骨架。零 RNG。前處理 disconnected + 孤立節點。"""
    import numpy as np, scipy.sparse as sp
    from scipy.sparse.linalg import lobpcg
    import networkx as nx
    # 1. 建對稱鄰接（無向化：引用方向對結構距離不重要）
    G = nx.Graph()
    G.add_nodes_from(range(n_nodes))
    G.add_edges_from((e["source"], e["target"]) for e in edges)
    coords = np.zeros((n_nodes, dim), dtype=float)
    # 2. 連通分量分解（R3/R1 FATAL：real 28 分量 / synth 117）
    comps = sorted(nx.connected_components(G), key=len, reverse=True)
    main = comps[0]                      # 主分量(real 570 / synth 10147)
    main_idx = sorted(main)
    sub = _spectral_main(G.subgraph(main), main_idx, dim, ranks)  # 見 2.2
    for k, gi in enumerate(main_idx):
        coords[gi] = sub[k]
    # 3. 小分量 + 孤立節點：確定性 hash 排到主團外圈固定球殼（R3 MAJOR）
    _place_islands(coords, comps[1:], main_radius_hint=1.0)        # 見 2.3
    # 4. 後處理：徑向密度均衡(R5/R2/R6) + z 軸 sqrt(λ) 平衡
    coords = _density_remap(coords, main_idx)                      # 見 2.4
    # 5. 尺度校準到相機量級（R5：p95 非 max，防離群壓扁）
    coords = _rescale(coords, target_radius)
    # 6. 防呆：assert 無 NaN/Inf（R4 FATAL 上游兜底）
    assert np.isfinite(coords).all(), "layout produced NaN/Inf"
    return coords
```

**錨對照**：座標＝主分量 Laplacian 特徵向量 = 期許①結構決定形狀；全程零 `random`/`Math.random` = 期許②③約束①；dim=3 = 期許約束⑥。

### 2.2 主分量 spectral `_spectral_main`（R7 FATAL：避奇異 + 確定性初始）

```python
def _spectral_main(Gsub, main_idx, dim, ranks):
    import numpy as np, scipy.sparse as sp
    from scipy.sparse.linalg import lobpcg
    relabel = {gi: k for k, gi in enumerate(main_idx)}
    Gr = nx.relabel_nodes(Gsub, relabel)
    n = Gr.number_of_nodes()
    A = nx.to_scipy_sparse_array(Gr, nodelist=range(n), format='csr', dtype=float)
    deg = np.asarray(A.sum(axis=1)).ravel()
    L = sp.diags(deg) - A
    L = L + 1e-6 * sp.eye(n)             # R7：正則去奇異，避 sigma=0 命中零特徵值
    # 確定性初始向量 v0=deg/‖deg‖（R2：降跨平台漂移，非隨機 v0）
    base = deg / (np.linalg.norm(deg) or 1.0)
    X = np.column_stack([base * (j+1) for j in range(dim+1)])  # 確定性張成
    vals, vecs = lobpcg(L.tocsr(), X, largest=False, maxiter=200, tol=1e-7)
    order = np.argsort(vals)
    vecs = vecs[:, order[1:dim+1]]       # 丟主分量唯一 λ0≈0，取 λ1..λdim
    return _canonicalize(vecs, deg)      # 見 2.5
```

def _place_islands(coords, small_comps, main_radius_hint):
    import numpy as np, hashlib
    m = sum(len(c) for c in small_comps)
    placed = 0
    for c in small_comps:

            # 確定性 hash：同 node.i 每次同位置（期許②）

### 2.4 徑向密度均衡 + z 平衡 `_density_remap`（R5/R2/R6 MAJOR：穿梭尺度）

```python
def _density_remap(coords, main_idx):
    import numpy as np
    c = coords.copy()
    # z 軸 sqrt(振幅) 平衡，抗薄餅坍縮（R6）
    for ax in range(3):
        amp = np.std(c[main_idx, ax]) or 1.0
        c[:, ax] = c[:, ax] / np.sqrt(amp)
    # 徑向 rank-based 重映射：按到原點距離排序→均勻重佈半徑（R2/R5）
    r = np.linalg.norm(c, axis=1)
    eps = 1e-9
    order = np.argsort(r)
    ranks = np.empty_like(order); ranks[order] = np.arange(len(r))
    target_r = (ranks + 1) / len(r)           # 均勻 0..1，純函數零 RNG
    scale = target_r / (r + eps)
    return c * scale[:, None]
```

**錨對照**：徑向密度均勻→近距不糊、遠景不空洞 = 直接解 user 期許⑦補充的兩反 pattern；角度結構不動（只改半徑）→「距離反映關聯」大方向保留。⚠ **真 trade-off（commander 標記回拋 user）**：徑向重映射讓「絕對歐氏距離」不再嚴格等於「譜距離」，換取穿梭可用性——這是 user 期許①「距離由關聯決定」與⑦「穿梭美感」的內在張力，見 §6 human 複核 #2。

**結論**：
1. 純 spectral（pure/remap/louvain/換樣本）皆產生「中心密核+輻射散點」，非漂亮分離團塊——真實代碼圖普遍有 utility 超級 hub（index_project deg117 / get deg311），全域 Laplacian 數學上必然把多數節點壓向中心。換樣本(sancio)沒解決，因為它的 hub 更誇張。
2. **group-in-a-box（每 Louvain 模組強制排球面 + 群內 spectral）達成 ratio 0.02 強團塊分離**，matplotlib 確認漂亮分離彩色團塊。「漂亮分離團塊 + 結構決定（群內位置）+ 確定性（全程無隨機）+ 每專案不同（Louvain 模組數/大小/群內結構各異）」四者兼得。
3. **WebGPU 渲染瓶頸（最後一哩，viz 工程非演算法）**：v3 節點渲染太弱（暗色+小+sprite 邊緣漸層），視覺全靠連線撐；超級 hub 的大量邊用 AdditiveBlending 疊成亮束糊掉團塊。要在最終 viz 顯示團塊需 (a) 大幅提亮+放大節點讓節點主導 (b) 連線改 metric backbone / 隱藏 hub 邊（紅藍 R6）。
