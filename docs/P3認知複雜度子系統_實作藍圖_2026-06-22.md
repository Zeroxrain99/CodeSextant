## §1 演算法規則（查證版）

三條基本原則：①忽略不增理解負擔的結構（method 宣告本身、null-coalescing 等）②每次「打斷線性控制流」+1 ③巢狀時，打斷流的結構**額外**+當前巢狀深度。

| 類別 | 結構 | 計分 |
|---|---|---|
| **B1 基本增量（+1，無論巢狀）** | `if`、`else if`、`else`、ternary、`switch`、`for`/`foreach`/`while`/`do-while`、`catch`/`except`、帶標籤跳轉(`break LABEL`/`continue LABEL`/`goto`)、**連續 binary 邏輯運算子(每個 run +1)**、**recursion(直接遞迴呼叫 +1)** | +1 each |
| **B2 增巢狀層（給「裡面的」結構加權的容器）** | `if`、`else if`、`else`、ternary、`switch`、loops、`catch`/`except`、**巢狀 function/lambda** | nesting += 1 |
| **B3 巢狀增量（除 B1 的 +1 外，再 +當前巢狀層數）** | `if`、ternary、`switch`、loops、`catch`/`except` | +nesting |

**最易錯的 5 個細節（釘死）**：
1. `else`/`else if`：拿 B1 +1，**不拿 B3 巢狀增量**（同一決策鏈延續、不重複懲罰）；但**會**增 B2 巢狀層給其 body。
2. **巢狀 function/lambda**：增 B2 巢狀層，但宣告本身**不**+1（B1 不含）。讓巢狀閉包裡的控制流更貴，但宣告閉包本身不加分。
3. `switch`：**整個 switch +1（+nesting）一次**，裡面的 `case` **不各加**（這是 cognitive 與 cyclomatic 的關鍵差異）。
4. boolean run：一串 `&&`/`||`，每個「連續同運算子的 run」+1。`a&&b&&c`=1、`a&&b||c`=2、`a||b&&c||d`=3。
5. **不算**：`try` 本身（只 `except`/`catch` 算）、`finally`、`with`(Python)、無標籤 `break`/`continue`、循序碼。

**黃金案例 sumOfPrimes 驗算（期望 7）**：
```
for i        nesting0: B1+1 +B3 0 = 1   → 進入 nesting=1
  for j      nesting1: B1+1 +B3 1 = 2   → 進入 nesting=2
    if       nesting2: B1+1 +B3 2 = 3   → 進入 nesting=3
      continue LABEL:  B1+1 (無B3)  = 1
合計 = 1+2+3+1 = 7 ✓
```

## §2 tree-sitter per-language taxonomy（_probe_cflow.py 坐實 2026-06-22）

**高信心語言集（計權）= {python, javascript, typescript, tsx}**；其餘 12 語言 cognitive=NULL（UNKNOWN 中性、不計入 health、不洗滿分）。理由：控制流 grammar 跨語言差異大（Go `expression_switch_statement`、Ruby `case`、Kotlin `when`、Swift `guard`…）、逐一驗透徹是 P4+ 工程；P3 先把 4 個高信心語言做穩。

### Python（probe 坐實）
- B1+B3（增量+巢狀增量+增巢狀層）：`if_statement`、`for_statement`、`while_statement`、`conditional_expression`(三元)、`match_statement`(當 switch)、`except_clause`
- B1 only（+1 無 B3，但**增巢狀層**）：`elif_clause`、`else_clause`
- 增巢狀層不加分：`lambda`、巢狀 `function_definition`
- boolean：`boolean_operator`（field `operator` ∈ {`and`,`or`}；巢狀 `boolean_operator` 攤平數 run）
- comprehension（實作選擇，白皮書未明訂 Python comprehension）：`for_in_clause` 當 loop（B1+B3+巢狀層）、`if_clause` 當 B1+1。canary 標明此選擇。
- ⛔ 不算：`with_statement`、`try_statement` 本身、`finally_clause`、`case_clause`（switch 整體算一次）、`assert_statement`

### TypeScript / JavaScript / TSX（probe 坐實）
- B1+B3：`if_statement`、`for_statement`、`for_in_statement`(for-of/in)、`while_statement`、`do_statement`、`ternary_expression`、`switch_statement`、`catch_clause`
- B1 only（+1 無 B3，增巢狀層）：`else_clause`（注意：TS `else if` = `else_clause` 內巢一個 `if_statement`；要防雙算 → else_clause 直接子是 if_statement 時，該 if 視為 else-if 只 +1 無 B3）
- 增巢狀層不加分：`arrow_function`、`function_expression`、巢狀 `function_declaration`
- boolean：`binary_expression`（field `operator` ∈ {`&&`,`||`}；⛔ 不含 `??`（白皮書 ignore null-coalescing，對抗 review HIGH 修正）；過濾掉算術/比較運算子；巢狀攤平數 run）
- ⛔ 不算：`try_statement` 本身、`finally_clause`、`switch_case`/`switch_default`、`jsx_element`/`jsx_expression`（JSX 不增控制流）

**else-if 雙算防護（關鍵）**：
- Python：`elif_clause` 是獨立節點 → 直接識別、+1 無 B3、增巢狀層。乾淨。
- TS：`else if` = `else_clause(if_statement(...))`。walker 進 `else_clause` +1（無 B3）、增巢狀層；但其直接子 `if_statement` 不可再當正常 if 計分（會雙算）。處理：進入 if_statement 前檢查 parent 是否為 else_clause 且自己是其唯一控制子 → 是則 skip 自己的 B1/B3（已由 else_clause 計），但仍遞迴 body。
